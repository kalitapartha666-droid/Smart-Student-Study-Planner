Smart Student Study Planner
Project Overview

The Smart Student Study Planner is a web-based application designed to help students organise their daily study schedules, manage academic tasks, and improve time management.

Objectives
Help students plan their daily studies.
Organise subjects and study tasks.
Track completed and pending tasks.
Improve productivity and time management.
Technologies Used
HTML – Website structure
CSS – Website design and styling
JavaScript – Functionality and interactivity
Main Features
Student-friendly interface
Study task management
Subject organisation
Task completion tracking
Easy-to-use planner
How to Run
Download or clone this repository.
Open the project folder.
Open index.html in a web browser.
